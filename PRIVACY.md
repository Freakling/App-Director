# Privacy Policy

App Director is a locally-run tool with minimal data handling.

**Data Access:** The tool reads your app project files (design documents, code, tasks, settings, and git history) to enable AI assistance. It does not collect personal information such as names or emails. At session start a hook also reads the names, ids and ages of the processes on this machine, to report ones left running by an ended session. It stores nothing and sends nothing. To turn it off, set `APP_DIRECTOR_ORPHAN_REPORT=0`.

**Local Storage:** All output stays on your machine: workflow files, code generated by the assistant, approved commits, and project state in the `.app-director/` folder.

**No Telemetry:** App Director has no telemetry or analytics, and, apart from the release check below, sends nothing to us or to any other service.

**Release check:** At session start, at most once a day, a hook reads the public list of App Director's release tags from GitHub (`git ls-remote`), to tell you when the project is behind the latest release. It sends no project data; GitHub sees an ordinary request from your machine, under GitHub's terms. To turn it off, set `APP_DIRECTOR_RELEASE_CHECK=0`, for example in `.claude/settings.local.json` › env.

**GitHub Downloads:** When fetching App Director via the skill or plugin, the tool downloads from GitHub under GitHub's terms. No project data is uploaded during this process.

**AI Assistant Privacy:** Your chosen assistant (such as Claude) handles your conversations and files according to its own provider's privacy policy. App Director does not modify this arrangement.

**Deletion:** Since everything remains in your repository, removing App Director files removes the tool entirely.

**Support:** Report issues at https://github.com/Freakling/App-Director/issues.
